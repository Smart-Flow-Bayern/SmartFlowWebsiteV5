Stand 2026-10-27. Die Rechtstexte wurden aus V4 (DE) übernommen. Am 2026-10-27 wurde nur Abschnitt 3 „Hosting“ der Datenschutzerklärung ergänzt. Von Leon/Anwalt zu prüfen:

- `public/datenschutz.html`, Abschnitt 3 „Hosting“: neu geschrieben für GitHub Pages (GitHub, Inc., USA). Rechtsgrundlage Art. 6 Abs. 1 lit. f DSGVO, Drittlandübermittlung über das EU-US Data Privacy Framework. Quellen: Datenschutzerklärung von GitHub (Anschrift, DPF-Zertifizierung) und GitHub-Doku „What is GitHub Pages?“ (IP-Protokollierung zu Sicherheitszwecken). Die frühere Aussage, der Hoster befolge unsere Weisungen, ist entfallen. Für GitHub Pages im Free-Plan ist kein Auftragsverarbeitungsvertrag bekannt. Ob GitHub hier als Auftragsverarbeiter oder als eigener Verantwortlicher gilt, ist zu prüfen.

- Abschnitt 7 „Server-Log-Dateien“ zählt Datenarten auf, die GitHub nicht im Einzelnen dokumentiert (belegt ist nur die IP-Adresse). Wortlaut prüfen.
- Die englische Datenschutzerklärung gibt es nicht mehr (Seite nur auf Deutsch).
